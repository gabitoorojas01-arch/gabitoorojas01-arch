### 🚀 Proyecto Destacado

#### 🔧 [MecaCloud SaaS — Plataforma de Gestión para Talleres Automotrices](https://github.com)
Sistema SaaS Full-Stack desarrollado con **Java 21, Spring Boot 4, PostgreSQL 16, React y Tailwind CSS v4**, contenedorizado con **Docker** y listo para despliegue en la nube.
* **Arquitectura y Seguridad:** API RESTful protegida con autenticación **JWT**, cifrado **BCrypt** y control de acceso granular por roles (`ADMIN`, `RECEPCION`, `MECANICO`).
* **Módulos Clave:** Panel gerencial de KPIs en tiempo real, Tablero Kanban operativo con integración a WhatsApp, generación automática de facturas en PDF, hoja de vida vehicular por placa e inventario inteligente con exportación a Excel (`.xlsx`).
